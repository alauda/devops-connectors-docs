# JFrog Connector Automatic Creation Tekton Task

> Run the install command on this page **once per cluster** (admin only) to install the Task and the tool-image ConfigMaps. Day-to-day users only create TaskRuns — see the [how-to guide](./using_jfrog_connector_automatic_creation_task.mdx) for end-to-end examples, and [Automatically Provision JFrog Resources When a Project Is Created](./automatically_provision_jfrog_for_a_project.mdx) for running it from a namespace event.

Set the variables, then run the command below:

- `REGISTRY`: the registry host that stores the `alauda-connectors/connectors-extensions/jfrog-connector-automatic-creation` image.
- `TARGET_NS`: the namespace where you want to install the Task. The tool-image ConfigMaps are installed in `kube-public`.
